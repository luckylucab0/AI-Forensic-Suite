# ADR 0000: Template

- **Status:** template
- **Date:** not applicable

Copy this file, give it the next free number, and keep it short. An ADR is a record of a
decision and its price, not a design document.

## Context

What forced a decision. Constraints, the thing that does not work otherwise, what was
already true before.

## Decision

What was decided, in the present tense, specifically enough that someone can check whether
the code follows it.

## Consequences

What this buys, and what it costs. Name the cost honestly: an ADR without a cost section
is usually a decision nobody examined. Say what would make us revisit it.

## Alternatives considered

The realistic ones only, one line each, with the reason they lost.
